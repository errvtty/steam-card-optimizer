Guía de uso

1. Steam OpenID

El sitio no pide la contraseña de Steam. Steam devuelve el SteamID64 mediante OpenID.

2. Inventario

El backend consulta el inventario 753/6 y detecta objetos de tipo Trading Card.

3. Mercado

Los enlaces llevan al listing exacto. El usuario termina la compra dentro de Steam.

4. Precio

El proyecto incluye una ruta server-side para priceoverview, con caché y tolerancia a errores.

5. Multiusuario

Cada visitante autenticado tiene su propia sesión y su SteamID64. No se mezcla el inventario entre usuarios.

6. Hosting

Para producción usa un hosting Node.js con HTTPS. Netlify por sí solo no ejecuta este backend Express.
